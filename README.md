## Projets

### SILIMU — réservation de billets lacustres

Application de réservation de billets de transport sur le **lac Kivu** et le
**lac Tanganyika** : recherche de traversées, réservation, billet avec code,
paiement mobile (Orange Money, Airtel Money, M-Pesa).
